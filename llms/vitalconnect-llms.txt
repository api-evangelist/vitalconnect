# VitalConnect

> VitalConnect is a San Jose, California medical device company. Its single-use VitalPatch
> adhesive biosensor streams continuous physiological data — single-lead ECG, heart rate, heart
> rate variability, respiratory rate, skin temperature, body posture, fall detection and step
> count — through VistaPoint relay software on a VistaTablet or VistaPhone to the cloud-hosted
> VistaCenter clinician dashboard, for mobile cardiac telemetry, extended Holter, remote patient
> monitoring, hospital-at-home, inpatient expansion and decentralized clinical trials.

## API status

VitalConnect HAS an API and does NOT publish it. The FDA-cleared VitalPatch Instructions For Use
state that the VitalPatch device "is compatible with Relay devices and software developed with the
VitalConnect Application Programming Interface (API)" and direct integrators to contact
VitalConnect, Inc. to obtain MAN-001, the VitalConnect Platform Integration Manual — Developer
Guide. That document is not published at any public URL. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL definition, no SDK in any public package registry, no
Postman collection, no MCP server, no agent card and no /.well-known/ discovery document. The
platform hosts are published only as the wildcard `*.prod.vitalconnect.com`.

The one integration surface documented in public is VistaCenter's outbound webhooks.

## Integration surface

- [VistaCenter webhooks](https://vitalconnect.com/docs/man027/MAN-027_RevG_VistaSolution-IT-Admin-Guide.pdf): VistaCenter POSTs notification, new-patient, new-device and device-updated events to a subscriber-supplied Target URL. Payload carries an event type, an event ID and an event-identifying object. No published schema, signing scheme or retry policy.
- EHR read-back is explicitly unsupported: MAN-027 states that, to maintain HIPAA compliance, the VitalConnect solution does not support retrieval of information from EHR systems.

## Specs

- No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema or Postman collection is published by VitalConnect.
